# Etapa 4 — Código Seguro e Testes de Segurança

_Etapa planejada._ Esta pasta receberá, para cada uma das duas práticas de
código seguro selecionadas:

- os testes de segurança (caso válido e caso malicioso), escritos **antes** da
  implementação;
- a implementação, o pseudocódigo ou a descrição detalhada da prática;
- a referência da OWASP Cheat Sheet Series ou do ASVS utilizada.
